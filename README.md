# Safaï Luxury Fragrance Website

This project is an elegant and premium perfume brand website designed to showcase Safaï's luxury fragrances. The website features a modern design with a luxurious feel, providing a smooth and engaging user experience.

## About the Website

The website includes the brand story, product collection, fragrance notes, customer reviews, FAQ, and contact section. Its primary goal is to present a premium fragrance experience while allowing users to explore the products with ease.

## Features

- Luxury landing page with an animated hero section
- Featured collection showcasing premium perfumes
- Brand story and About section
- Why Choose Us section
- Detailed fragrance notes for each perfume
- Customer testimonials section
- FAQ section
- Contact section with WhatsApp integration
- Smooth animations and scroll-based interactions
- Fully responsive design for both mobile and desktop devices

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion

## Getting Started

1. Install the dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

## Build for Production

```bash
npm run build
```
